      碼上解答：QR Code 常見問題

      QR Code 會過期嗎？

      不會。QB Code 做的是靜態 QR Code，網址直接寫進圖案裡，不經過任何轉址服務，所以沒有到期日，也不限掃描次數。只要網址本身還能開，印出去的 QR Code 就一直有效，狸所當然。有些 QR Code 服務會先把人導到自家的轉址網址，服務停了或試用期過了，QR Code 就跟著失效。

      QR Code 加上 logo 還掃得出來嗎？

      掃得出來。QR Code 自帶糾錯能力，QB Code 用最高的 H 級，能修復大約 30% 的損壞。放九尾狐之前，會先算出牠蓋住哪些資料，確保最吃緊的區塊只用掉六成修正能力，剩下的留給髒污、反光和手震；放不下時就換大一號的版本，或把九尾狐縮小。

      要付費或註冊嗎？

      都不用。貼上網址碼上就好，下載 PNG、SVG 或直接複製圖片都免費，也不用註冊帳號或登入。

      我貼上的網址會被上傳嗎？

      不會。QR Code 全在你的瀏覽器裡算好，網址不會送到任何伺服器。為了下次打開時還在，網址只存在你自己瀏覽器的本機儲存空間。

      該下載 PNG 還是 SVG？

      貼到網頁、簡報或傳訊息，用 PNG（大約 1024 px）就夠了；要印刷、做海報或大圖輸出，選 SVG，怎麼放大都不會糊。「複製圖片」會把 PNG 放進剪貼簿，直接貼上就能分享，有狐同享。

      QR Code 印出來掃不到怎麼辦？

      先確認印得夠大：寬度至少 2 公分，掃描距離越遠就要越大，大約是距離的十分之一。四周的淺色邊框不要裁掉，也別印在反光或深色的材質上。網址越短，QR Code 的格子越少、越好掃，可以先拿掉追蹤用的參數（例如 utm_ 開頭的那些）。
